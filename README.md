# LED Fabric Layout Simulator

Plan how to sew a fixed-spacing string of LEDs onto a piece of fabric. Preview where the LEDs land, check how the pattern looks when the fabric wraps into a cylinder, and print a full-size sewing template.

**[Try the simulator](https://forresttrepte.github.io/LEDStringFabricLayout/)**

## Example layout

![Example LED layout showing the wire path and LED positions on fabric](example-layout.svg)

## Features

- Set the fabric dimensions, LED spacing, and LED count.
- Try sharp corners, rounded U-turns, and diagonal turns.
- Compare the flat layout with a rotating cylinder preview.
- Search for layouts that spread the LEDs across the fabric and reduce visible patterns.
- Save and share named presets.
- Export a full-size SVG, with a black-on-white view for printing.
